# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, criticise code and ideas rather than people, and
accept that others may decide differently. Harassment, insults and personal attacks are not
tolerated in issues, pull requests, reviews or any other project space.

## Reporting

Use GitHub's **Report content** (the `…` menu on any comment, issue or pull request) or
[report the account](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Maintainers see reported content and act on it: they hide or delete comments, lock threads and
block accounts that break these rules.
