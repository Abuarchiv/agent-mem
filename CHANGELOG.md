# Changelog

## 1.0.0

- Standalone local-first V1 repository.
- Source-only capture and retrieval with SQLite/FTS5 and multilingual E5.
- Optional bounded local reranking and structural metadata search.
- stdio MCP with recall, get, forget and source-backed write.
- Codex, OpenCode and Copilot CLI/app local-worktree adapters.
- Removed generative providers, extraction workers, UI, HTTP and subscription paths from the V1 repository.
